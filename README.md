# Search-for-FoxA-repressor
This is a folder I created to share the code I used to search for a potential repressor of FoxA in the Brandenburg et.al 2025 dataset, on the criteria that the candidate would be co-expressed with more than one of the maker genes of the region of interest (Wnt5, IxA, Nk1, suPaxB) & not coexpressed with FoxA at gastrula stage.
I tried out several stages (20 hpf and 24 hpf), and raised/lowered the treshold for FoxA, but here I only give the output for 20hpf and strict no-coespression (Foxa_vs_TF.xlsx)
